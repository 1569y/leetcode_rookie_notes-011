# 哈希表是什么


## 哈希表可以理解成一种 “键 → 值” 的映射结构。

也就是 "key → value"

> 例子: 每个人都有自己的学号, 名字是key, 检索的时候从人名去检索学号, 所以学号是value 

> ( "Ann" → 25 也就是有个名字叫Ann 的学号是25 )

## python中实现哈希表一般都是通过 dict :

```
d = {}
```

例如：

```
d = {
    "a": 2,
    "b": 1
}
```

可以理解成：

```
"a" -> 2
"b" -> 1

# print
print(d["a"]) = 2 # 检索key,获得value
```

## 平常是这样判断在与否

```
if "a" in d:
    print("存在")
```

> 因为不确定"a" 存在与否, 所以改为使用 get() , 直接 d["a"] 可能会报错

也就是 `d.get("a", 0)` :
- 若是 "a" 的 value 已经存在, 返回 value
* 若是不存在, 返回0

例如:

```
d = "abaca"
result = {}

# 把 d 转换为哈希表, 统计出现次数
for num in d:
    result[num] = result.get(num,0) + 1
```

```
result = { "a":3, "b":1, "c":1 }
```

## 在这道题里，我们可以用：

- key -> 字符
* value -> 字符出现的次数

所以哈希表很适合拿来做 **字符计数**。

对此, 常见写法：

```
d[key] = d.get(key, 0) + 1
```

意思是：
- 如果 value 已经存在，就在原来的次数上加 1；
* 如果不存在，就从 0 开始加 1。


# 思路1

> 基础版的

这道题需要判断：ransomNote 中需要的每个字符，magazine 中是否都有，并且数量是否足够。

> 我还纠结过是否要按顺序, 发现其实不用, 就是字符的数量够不够

```
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        r = {}
        m = {}
        
        # 最开始可以分别统计两个字符串中每个字符出现的次数：
        for ra in ransomNote:
            r[ra] = r.get(ra, 0) + 1

        for ma in magazine:
            m[ma] = m.get(ma, 0) + 1
            
        # 对比数量是否足够
        for num in r:
            if r[num] > m.get(num, 0):
                return False

        return True
```

这里：

```
r[num] > m.get(num, 0)
```

表示 ransomNote 需要的字符数量，比 magazine 能提供的还多，所以无法构成，返回 False。


## 最开始我是这样写的

```
        for num in r:
            if m.get(num,0) == 0:
                return False
            elif m.get(num,0) != 0 and r[num] > m[num]:
                return False
```

因为是两个情况判定 false :

**(1)  r[num] > m[num]**

- 虽然有，但数量不够
* 就是如果 m 中关于这个 "value" 的数字是少于r 的话，
* 那就代表说 m 中的字符不够 r 的字符使用, 也就是无法构成 r 的。

**(2)  m.get(num,0) == 0**

- m 中没有那个 "value" 的字符

### 可以被简化

m.get(num, 0) 是0，那么它本身也一定满足：

```
r[num] > m.get(num, 0)
```

> 因为 r[num] 至少是 1。

> 而 m.get(num, 0) 之前说了, 可以是 num的value ( 也就是m[num] ) 也可以是 0

所以这两个条件其实可以合并成一个：

```
for num in r:
    if r[num] > m.get(num, 0):
        return False
```

## 同时要注意:

return True 要放在循环外面，因为必须等 **所有字符** 都检查完，才能确认可以构成。

> 若是 return true 是放在 for 这个循环里面的，那它就可能会出现一个通过了,  直接返回True，然后后面有字符未被检查的问题。

# 思路2

> 内存少点

其实不需要建立两个哈希表。只需要把 magazine 看成一个 **字符库存表**。

> 就是我们能调用多少字符先统计一下

```
magazine -> 建立库存

ransomNote -> 提出需求

有库存 -> 减 1

没库存 -> False

全部满足 -> True
```

## 先统计 magazine 中每个字符有多少个：

```
m = {}

for ma in magazine:
    m[ma] = m.get(ma, 0) + 1
```

## 然后遍历 ransomNote。

- m.get(value,0) == 0 就是没有库存 -> 不够 -> 返回false
* 有库存 -> 每需要一个字符，就从库存中减一个

```
        for value in ransomNote:
            if m.get(value,0) == 0:
                return False
            else:
                m[value] -= 1
```

## 最终代码

```
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        m = {}

        for ma in magazine:
            m[ma] = m.get(ma,0) + 1

        for value in ransomNote:
            if m.get(value,0) == 0:
                return False
            else:
                m[value] -= 1

        return True
```

# 复杂度


## 第一版

分别遍历一次 ransomNote、一次 magazine，最后再遍历一次 r。

> n = len(ransomNote)，m = len(magazine)。

- 时间复杂度: O(n+m)
* 空间复杂度: O(n+m)


## 第二版

- 时间复杂度: O(n+m)
* 空间复杂度: O(m)
