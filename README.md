# 说在前面
本项目是我刷 leetcode 题过程中一题一题积累的笔记。 主要覆盖 LeetCode 面试 150 题与 Hot100 高频题中的题目，正在持续更新ing

我本身算法基础薄弱，很多知识点几乎遗忘，属于从零重新捡起来的小白。

所以这份笔记没有大佬式的一眼看出答案，而是回归基础，完整记录我的思考：一开始怎么想、踩了哪些坑、思路卡在什么地方，又是如何慢慢修正，走向正确解法。  

所有题解尽量用通俗直白的语言拆解，还原咱们小白真实刷题的心路，希望能帮到和我一样基础一般的同学，能够看懂每一步是怎么想到解法的~
