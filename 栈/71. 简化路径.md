# LeetCode 71. 简化路径｜小白刷题实录：从一脸懵到栈思路
题目链接： [https://leetcode.cn/problems/simplify-path/](https://leetcode.cn/problems/simplify-path/)

拿到这道题的时候我第一眼就头大。 

题目给一个 Unix 绝对路径，像 `/home/user/Documents/../Pictures`，要求转换成规范路径。 

写了一大堆， 什么 斜杠、单点、双点，还有三个点 `...`，我当时一下子分不清哪些是特殊符号，哪些只是普通名字。

所以，我就先把题目里4种情况整理了一下：
- `"."`：当前目录，不用做任何操作
- `".."`：回到上一级目录
- `"//"`：连续多个斜杠，等价于单个`/`
- `"..."`、`"...."`：**单纯目录名字，没有特殊含义** 
	- 这是我踩的第一个大坑

**举例子：**
`/home/user/Documents/../Pictures` 
- 走到`Documents`之后遇到`..`，
	- 就要退回去，删掉`Documents`，
- 最后路径变成 `/home/user/Pictures`。

这道题本质需求：从左往右一段一段读路径，只保留最终有效的目录。

## 一、我最开始踩的大坑：纠结点的数量
刚读题，我的第一个错误想法：

> 只要出现点就要小心，是不是要统计字符串里有几个点？ 
> 一个点是当前目录，
> 两个点返回上级，
> 那三个点、四个点是不是别的特殊命令？

我还在草稿里琢磨怎么判断点的个数，反复想边界。 。

后来读完题目仔细看要求才恍然大悟：**只有`.` 和 `..` 是特殊指令**。 

只要不是这两个，不管有多少个点，全部当成普通目录名称，不用额外处理。 

> 不要看他们说了一堆，其实和普通的字母目录名是一样的

这一步直接帮我砍掉一大堆没必要的判断逻辑。

## 二、多个连续斜杠怎么处理？

比如 `/home//foo/`，要变成 `/home/foo`。

我第一反应：写循环把连续 `/` 全部替换成单个 `/`。

> 想也知道， 很麻烦， 因为不知道会有多少个 `/`

后来发现可以直接用**字符串分割**：

```python
path.split("/")
```

举个例子：

`path = "/home//foo/"`

执行 `path.split("/")`，

会得到：`["", "home", "", "foo", ""]`

🚩 重点：两个斜杠中间切开之后得到的是空字符串 `""`，不是空格！

所以多个 `/` 的问题，**不需要专门写代码去合并斜杠**。

>分割完成之后，遍历片段的时候，直接 **跳过空字符串** 就行。

一下子就简化很多。


## 三、逐个处理每一段路径片段

分割完得到一堆片段，我们直接循环挨个判断：

**1. 片段是 `"."` 代表当前目录，原地不动，直接跳过。**

```python
if num == ".":
    continue
```

**2. 片段是 `".."` 代表返回上一级目录。**

比如路径现在是 `/home/user/Documents` : 

遇到 `..`，就要删掉它前面第一个, 也就是当前路径最后面的 `Documents`。

🔖 这里我当时卡了很久：**用什么数据结构能方便删掉最近加入的目录？**

列表当然可以，但是这个场景有个特点：**我们只需要删除最新加进去的那一项**。

> 最新进来，最先被拿走，这不就是 **栈（后进先出）** 的特点吗？
> 每进入一个目录，就往栈里追加；
> 遇到 `..`，就弹出栈最后一个元素。

🚩 易错边界：已经在根目录 `/` 的时候，不能继续往上回退。

例如 `/../`，栈已经是空的，这时不能 pop，否则直接报错。

所以 pop 之前，必须判断栈不为空：

```python
elif num == "..":
    if stack:
        stack.pop()
```

**3. 剩下的情况**

比如 `"..."`、`"home"` 

只要不是 `.` 、不是 `..`、也不是空字符串，全部视为普通目录，直接加入栈。

```python
elif num:
    stack.append(num)
```

> `elif num:` 等价于 `elif num != ""`，空字符串会被跳过。


## 四、完整走一遍样例

**输入:** `/.../a/../b/c/../d/./`

**使用**: `path.split("/")` 

**结果:** `["", "...", "a", "..", "b", "c", "..", "d", ".", ""]`

**逐个处理：**
- `""` → 跳过
- `"..."` → 普通目录，入栈
- `"a"` → 入栈
- `".."` → 栈不为空，弹出 a
- `"b"` → 入栈
- `"c"` → 入栈
- `".."` → 弹出 c
- `"d"` → 入栈
- `"."` → 跳过
- `""` → 跳过

最后栈内结果：`["...", "b", "d"]`，这就是所有有效的目录。


## 五、我最开始写的版本（有逻辑，但写法很笨）

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        parts = path.split("/")
        stack = []

        for num in parts:
            if num == ".":
                continue
            elif num == "..":
                if stack:
                    stack.pop()
            elif num:
                stack.append(num)
        
        n = len(stack)
        s = "/"
        for i in range(n):
            if s == "/":
                s = s + str(stack[i])
            else:
                s = s + "/" + str(stack[i])
        return s
```


## 六、拼接字符串：我踩的另一个坑

处理完所有片段，栈里保存了有效目录，需要 **拼接成最终路径**。

我使用的方法比较笨 - 手动循环拼接字符串：

```
n = len(stack)
s = "/"
for i in range(n):
    if s == "/":
        s = s + str(stack[i])
    else:
        s = s + "/" + str(stack[i])
```

> 此时 `stack` 里面存的是一个个目录名，例如 `["home", "user", "Pictures"]`。 
> 我们目标：拼接成 `/home/user/Pictures`

**初始：** `s = "/"`，保证路径一定是以 `/` 开头（Unix绝对路径要求）。

**过程:** 循环逐个取出 stack 里的目录：
1. **第一次循环（i=0，stack[i] = "home"）** 
	1. 此时 `s == "/"`，说明现在字符串只有根符号，
	2. 后面直接接上目录名，**不能再加斜杠**。 
	3. `s = "/" + "home"` → `s = "/home"`

2. **第二次循环（i=1，stack[i] = "user"）**
	1. `s` 现在是 `/home`，不再等于单独的 `"/"`。 
	2. 所以要先加 `/`，再接目录：
	3. `s = "/home" + "/" + "user"` → `/home/user`

3. **第三次循环（i=2，stack[i] = "Pictures"）** 
	1. 同理：`s = "/home/user" + "/" + "Pictures"` → `/home/user/Pictures`

最终结果：`/home/user/Pictures`

**那栈为空的情况呢？**
`stack = []`，`n=0`，for循环 **根本不会执行**。 
s 保持初始值 `"/"`，正好对应根目录 `/`，边界也能处理。


逻辑 **能跑通，答案正确**，但是写法很笨拙, 效率也偏低。

后来我才知道 Python 里可以直接用 `join()`：  

**譬如:** `"/".join(["home", "user", "Pictures"])`  

> `"/"` 会插入到 stack (list) 的元素的 中间
  
会直接得到：  `"home/user/Pictures"`  
  
然后只需要在最前面补一个 `/`：  `"/" + "/".join(stack)`  
  
就能得到：  `"/home/user/Pictures"`  
  
而且连根目录的情况也顺便处理掉了。  
  
比如 ==栈为空==：  `"/".join([])` → `""`  
  
所以：  `"/" + ""` → `"/"`  
  
也就是说，原本需要手动循环、判断什么时候加 `/` 的那一大段代码，最后可以直接压成一行：  
  
```python  
return "/" + "/".join(stack)
```


## 七、优化后完整代码

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        parts = path.split("/")
        stack = []

        for num in parts:
            if num == ".":
                continue
            elif num == "..":
                if stack:
                    stack.pop()
            elif num:
                stack.append(num)
        
        return "/" + "/".join(stack)
```

## 八、复杂度分析

设：n 是原始 path 的字符串长度

- 时间复杂度 O(n)：split、遍历片段、join，都只是扫描字符串
- 空间复杂度 O(n)：最坏情况所有目录都保留在栈里


## 九、总结

这道题给我两个很重要的收获：

1. 如果需要**撤销最近一次操作**，优先想一想栈。
2. 不要看到一堆特殊字符就下意识写大量判断。仔细读题，分清哪些字符真的有特殊含义，很多猜想都是自己脑补出来的多余逻辑。
3. Python 的 `str.join()` 拼接列表字符串，比手动循环拼接简洁很多，减少出错机会。
